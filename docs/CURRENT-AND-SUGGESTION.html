01Navbar + CredentialRow
CURRENT
  • Sticky navbar — instant paint on load, no entrance animation.
  • CredentialRow — static credential badges (CPA, CIA, Odoo Partner). No animation.
  • Gold hairline draws left-to-right on nav link hover via <GoldHairline>.
SUGGESTION — Trust cascade on load

Stagger the credential badges in from below with a 40ms delay between each: opacity 0→1 + translateY 8px→0, ease-out-quart, 420ms each. The sequence reads left-to-right like a résumé being handed over — the first authority claim the page makes should feel deliberate, not instant.

Tool: motion/react — whileInView stagger, once:true, amount:0.8 staggerChildren: 0.04 · y: 8→0 · opacity: 0→1
02DiamondScrollHero — Entry (Above Fold)
CURRENT
  • HeroIntroOverlay cinematic sequence plays on first load.
  • R3F canvas: helix DNA strand, 8 diamonds, particle field.
  • Camera moves Y/Z via GSAP ScrollTrigger reading scrollProgressRef.
  • RotatingSpine applies 0.08 rad/s baseline Y rotation to the helix.
  • HeroTextOverlays headline + sub-headline fade in after intro.
SUGGESTION — Pre-scroll camera breath

Before the user scrolls, add a slow 6s Y-bob on the camera (sin(t × 0.4) × 0.06 world units) via useFrame. Cease the bob the moment scroll > 5px. This makes the 3D scene feel inhabited rather than frozen while the user reads the hero copy.

Tool: R3F useFrame lerp camera.position.y → sin(clock.elapsedTime * 0.4) * 0.06 Disable when scrollProgressRef.current > 0.005
03DiamondScrollHero — Mid Scroll (Diamond Captions)

  • CinematicCaption: full caption block fades in/out via Motion AnimatePresence.
  • Active diamond glows, scales, emits radial pulse (lerped diamondActiveness).

SUGGESTION — Caption word-by-word reveal

Split the headline into words and stagger each: opacity 0→1 + translateY 6→0 at 35ms per word. This mimics how a speaker delivers the line. Keep the exit as a single full-block fade for contrast.

Tool: motion/react — split headline by word staggerChildren: 0.035 · y: 6→0 · opacity: 0→1 Exit: whole div opacity 0, duration: 0.2
04Problem Section
CURRENT
  • RevealOnScroll on heading + intro paragraph (opacity + translateY, once:true).
  • GoldDrawIn — 1px gold line draws in from left as section enters viewport.
  • LivingCard on each of 3 problem cards (hover depth effect).
  • ScrollParallax on background gradient (20px Y amplitude).
  • Cost line items (AED 48K / 90K / 36K / 30K) render statically.
SUGGESTION — Cost counter roll-up ★ Top Priority

Animate each cost figure counting up from 0 to its value over 1.2s (easeOut), triggered when the cost grid enters the viewport. The total sum lands 400ms after the last item. Seeing numbers accumulate makes the pain visceral and quantified — the visitor feels the cost, not just reads it.

Tool: motion/react — useMotionValue + spring per figure Trigger: IntersectionObserver once, amount: 0.6 Total sum: delay 0.4s after last item
05Shield Section — Early (Tiles 0–2 assembling)
CURRENT
  • 750vh pinned scroll container.
  • Six hex tiles fly in from cluster origin → lock to TILE_LOCK_POS one-by-one.
  • Each tile: opacity/scale ramp during approach, snap to locked position.
  • TrackingCallout draws gold SVG connector line + glass card per tile after lock.
  • Pulsing dot at hex center while callout is active.
SUGGESTION — Tile lock micro-shake

When each hex tile reaches its locked position, nudge it 3px toward the cluster center then snap back over 120ms (spring, no bounce). This gives the assembly physical weight — like precision tiles being placed by hand.

Tool: R3F useFrame On frame tile transitions to LOCKED state: spike localPosition toward origin × 0.04 Release over 8 frames via lerp
06Shield Section — Mid (Tiles 3–5, frame + filler visible)
CURRENT
  • ShieldFrame CatmullRom tube fades in at its defined scroll window.
  • Final 3 hex tiles lock progressively.
  • SVG connector line draw-in per callout (strokeDashoffset, hex center → card).
  • FillerMesh honeycomb interior fades in as tiles complete.
SUGGESTION — Progressive frame glow intensify

As each tile locks (0→5), increase ShieldFrame tube emissive intensity: start 0.3, add +0.12 per locked tile, reach 1.0 when all 6 are in. The frame literally brightens as protection becomes complete.

Tool: R3F useFrame Derive lockedCount from scroll progress windows lerp shieldFrameMaterial.emissiveIntensity → (0.3 + lockedCount * 0.12)
